스코어 등급 — 시스템별 설정

FAB 마다 점수 분포가 달라 등급 경계도 다를 수 있습니다. 경계 시작점 미만은 정상(무알람)이고, 알람·케이스·등급 색·그래프 밴드가 전부 이 컷으로 계산됩니다. 조건: 1 ≤ 경계 < 위험 < 초위험 ≤ 100.

📄 FAB별 위험도 스코어 — 나란히 놓고 보기 — FAB 마다 보는 컬럼·임계가 어떻게 다른지, 그리고 한 FAB 만 아무리 나빠도 전체 점수는 경계에 못 간다는 구조를 실제 배점으로 펼쳐 놓았습니다.

등급 카운터 — 알람 표시

최근 N분 안에 등급이 몇 번 떴는지 세어, 실시간 관제·과거 데이터 조회 표의 종합점수 바로 옆 칸에 경계중 위험중 초위험중 으로 표시합니다. 점수와 등급 컷은 바뀌지 않습니다 — 이미 매겨진 등급을 세기만 합니다.

위 등급은 아래 등급을 포함해 셉니다 — 위험인 1분은 경계값도 넘은 1분이라 경계 카운트에도 들어갑니다. 안 그러면 점수가 위험에 눌러앉은 동안 경계 카운트가 0이 되어 제일 나쁜 구간에서 알람이 꺼집니다. 기준을 0 으로 두면 그 단계는 쓰지 않습니다.

시스템마다 따로입니다 — FAB 마다 등급 컷이 달라 등급이 뜨는 빈도도 다릅니다. 컷은 시스템별인데 세는 기준만 공통이면 어느 FAB 은 하루 종일 '위험중' 이고 어느 FAB 은 영영 안 뜹니다. 적용/미적용도 각각입니다.

과거 파일 정리 — 보관 기간

보관 기간(오늘 포함 N일)보다 오래된 날짜 파일을 하루 한 번(서버를 켤 때 · 날이 바뀐 뒤 첫 수집 때) 지웁니다. 지우는 것 — 원본 TOTAL · LLM 판단 · ML · raw 날짜 파일. ALL 과 FAB 전부 같은 기간입니다. 케이스·리포트·설정은 지우지 않습니다.

0 이면 지우지 않습니다(기본). 지운 날은 과거 데이터 조회에서 사라지고, 그날의 LLM 판단 기록은 다시 받을 수 없습니다. 보관 기간보다 오래된 날을 다시 확보해도 다음 정리 때 지워집니다. 저장만으로는 바로 지우지 않습니다 — 바로 지우려면 '지금 정리'.
