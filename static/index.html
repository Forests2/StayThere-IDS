      동작 방식

      'AI 판단 자동 실행' 을 켜면, AI 가 AI 공격·자동화 공격이라고 최소 확신 이상으로 판단할 때 차단·종료를 바로 해요. 대상은 DDS 가 실제로 잡은 IP·프로세스만 (이번 사건 + 최근 24시간 이상한 IP). AI 가 기록에 없는 대상을 말하면 무시해요 — 공격자가 기록에 심은 문장으로 방어 AI 를 속이는 조작을 막으려는 거예요. 내부망·신뢰 IP 는 자동 차단 안 해요.

(llama-cpp-python 으로 직접 로드 · Ollama 불필요 · GPU 전용: NVIDIA VRAM 24GB 이상, CPU 실행은 지원하지 않아요) API 주소나 키가 없거나 API 가 끊기면 이 모델이 바로 분석해요. 이 폴더에 .gguf 파일을 넣기만 하면 10초 안에 인식해요. 슬롯 경로를 비워 두면 작은(빠른) 모델 → 1번(항상 실행 · 즉시 판단), 큰 모델 → 2번(정밀 분석) 으로 자동 배정돼요. 5초 안에 판단하려면 1번은 1.5B~8B 크기(Q4)를 권해요.
